# Investment Portfolio Simulator (資産運用シミュレーター)

Streamlitを使用した、長期資産形成および資産取り崩しのシミュレーションアプリです。
新NISAなどを想定した積立投資の推移や、リバランス、老後の取り崩し計画（4%ルール等）を可視化します。

## 特徴

*   **資産形成シミュレーション**:
    *   初期投資額、毎月の積立額（NISA枠など）、期待リターンを設定可能。
    *   リスク資産と安全資産の比率を設定し、毎年リバランスを行うロジックを実装。
    *   `Decimal`型を使用した高精度な計算。
*   **資産取り崩しシミュレーション** (`app_zero.py`のみ):
    *   資産形成後の総額を元に、指定した期間・利率での取り崩し推移を計算。
    *   「定率取り崩し」による資産寿命の延命効果を確認可能。
*   **可視化**:
    *   Matplotlibによる積上げ棒グラフ（資産構成）と折れ線グラフ（取り崩し推移）。
    *   詳細な数値データのテーブル表示。

## ファイル構成

*   `app_zero.py`: **推奨（フル機能版）**。資産形成機能に加え、取り崩しシミュレーション機能を含みます。
*   `app.py`: 軽量版。資産形成シミュレーション機能のみを含みます。
