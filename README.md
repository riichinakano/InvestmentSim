# Investment Portfolio Simulator (資産運用シミュレーター)

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.28%2B-red.svg)](https://streamlit.io/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Streamlitを使用した、**ライフプラン統合型資産運用シミュレーター**です。
NISA制度を活用した長期資産形成、ライフイベントを考慮した支出計画、複数シナリオの比較を可視化します。

## ✨ 主な機能

### Phase 1: コア機能 ✅
- 📊 **基本投資シミュレーション**
  - 初期投資額、年間NISA投資額、期待リターン、投資期間の設定
  - リスク資産と安全資産の自動リバランス
  - NISA上限（1,800万円）の自動管理
  - `Decimal`型による高精度計算

- 👨‍👩‍👧‍👦 **ライフプラン統合シミュレーション**
  - 家族構成の入力（夫婦 + 子ども最大3人）
  - 家族年齢の自動計算と推移表示
  - ライフイベント（教育、住宅購入等）の登録と支出シミュレーション
  - イベント支出を考慮した資産推移の可視化

- 🌐 **多言語対応**
  - 日本語・英語の切り替え
  - 全UI要素の即座な翻訳

- 📈 **Plotlyによるインタラクティブグラフ**
  - ズーム、パン、ホバー情報表示
  - 積上げ棒グラフ（資産構成）
  - レスポンシブデザイン

- 💾 **データエクスポート**
  - CSV形式（UTF-8 BOM付き）
  - Excel形式（列幅自動調整、数値フォーマット）

### Phase 2: データ管理・比較機能 ✅
- 💿 **SQLiteデータベース統合**
  - シミュレーション設定の保存・読込
  - 新規保存・上書き保存
  - シミュレーション履歴管理（一覧・削除）

- 🔀 **複数シナリオ比較**
  - 最大3つのシナリオを同時比較
  - 総資産推移の折れ線グラフ表示
  - 最終年度の資産比較テーブル

## 📦 インストールと実行方法

### 1. リポジトリのクローンまたはダウンロード

```bash
git clone <repository-url>
cd assetsim
```

### 2. 仮想環境の作成と有効化（推奨）

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS/Linux:**
```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. 依存パッケージのインストール

```bash
pip install streamlit plotly pandas openpyxl
```

または

```bash
pip install -r requirements.txt
```

### 4. アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、以下のURLでアクセスできます:
- **ローカル**: http://localhost:8501

## 🎯 使用方法

### 基本的な使い方

1. **言語選択**
   - サイドバー最上部で日本語/Englishを選択

2. **投資パラメータ設定**
   - 初期投資額
   - 年間NISA投資額
   - リスク資産の期待リターン
   - リスク資産配分比率
   - 投資期間

3. **タブ1: 資産運用シミュレーション**
   - 基本的な資産推移を確認
   - NISA累積投資額と上限到達年を表示
   - CSV/Excelでエクスポート

4. **タブ2: ライフプラン表**
   - 家族構成を入力
   - ライフイベント（進学、住宅購入等）を登録
   - 統合シミュレーション実行
   - イベント支出を考慮した資産推移を確認

5. **シミュレーション保存**
   - サイドバーの「シミュレーションを保存」を展開
   - シミュレーション名を入力
   - 新規保存または上書き保存

6. **シミュレーション読込**
   - サイドバーの一覧から選択
   - 「シミュレーションを読込」をクリック

7. **タブ3: シナリオ比較**
   - 保存済みシミュレーションから最大3つ選択
   - 「比較実行」をクリック
   - 総資産推移と最終年度の比較を表示

## 📊 計算ロジック

### 年次処理フロー

1. **NISA積立実行**（上限1,800万円まで）
2. リスク資産に期待リターンを適用
3. ライフイベント支出処理（安全資産 → リスク資産の順）
4. 目標比率に基づくリバランス
5. 資産状態の記録

### NISA上限管理

- 累積投資額が1,800万円に達するまでNISA枠を使用
- 上限到達後は通常投資として継続（同じリターン率）
- 上限到達年を自動表示

### リバランス処理

- 年末に目標のリスク資産比率を維持するよう調整
- リスク資産 ↔ 安全資産の移動を自動計算

## 📝 制約事項

### 機能制約
- 家族構成: 最大5人（夫婦 + 子3人）
- イベント登録: 1年につき1件まで
- シミュレーション期間: 最大50年

### 計算制約
- リターン: 固定値（年ごとの変動なし）
- インフレ: 考慮しない
- 税金: 考慮しない（NISA前提）
